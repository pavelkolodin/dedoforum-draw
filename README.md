# nosql.ru paint attachment

Плагин (расширение) для Google Chrome. К форме ответа на форуме nosql.ru
(`https://nosql.ru/forum/topic.php?...`, `form#post_form`) добавляет **только маленькую кнопку
«Paint»** — сразу под строкой «Добавить вложение». Нажатие открывает модальное окно на весь экран,
в котором и находится рисовалка. Кнопка **SEND** превращает рисунок в файл `drawing-<время>.jpg`
(JPEG, качество **0.8**), кладёт его в `input#attachment[type=file]` — точно так же, как если бы вы
выбрали этот jpeg на диске — и закрывает окно.

Никаких библиотек: только стандартный DOM API и `<canvas>`.

## Установка

1. Скачать и распаковать архив в любую папку (например `C:\nosql-paint`).
2. В Chrome открыть `chrome://extensions`.
3. Включить «Режим разработчика» (справа сверху).
4. Нажать «Загрузить распакованное расширение» и выбрать распакованную папку
   (ту, где лежит `manifest.json`).
5. Открыть тему на nosql.ru, нажать «Написать» — под «Добавить вложение» появится кнопка **Paint**.

## Как пользоваться

Кнопка **Paint** в форме → модальное окно с рисовалкой:

| Элемент | Что делает |
|---|---|
| Холст 500×500 | рисуем мышью (или пальцем/стилусом); курсор остаётся обычной стрелкой |
| Круг под курсором | полупрозрачный кружок цвета кисти и точно её диаметра — показывает, куда лягут чернила; ушли мышью с холста — кружок исчез |
| Кнопки слева (1, 3, 5, 10, 15, 20, 30, 50, 100, 150, 200, 300) | толщина линии в пикселях (на кнопке нарисован штрих этой толщины) |
| Кнопки справа | цвет: белый, чёрный, красный, синий, зелёный, серый, фиолетовый, жёлтый (белый работает как ластик) |
| **CLEAR** | очищает холст (заливка белым) |
| **SEND** | сохраняет рисунок в JPEG (качество 0.8), вставляет файл в поле вложения и закрывает окно |
| **small** / **big** | уменьшают/увеличивают сторону холста на 50 px, пропорции остаются квадратными, нарисованное масштабируется |
| **×** / Esc / клик по фону | закрыть окно без вложения |

Рядом с кнопкой **Paint** после успешной отправки появляется надпись «прикреплено: drawing-….jpg» —
вложение уже в форме, остаётся только нажать кнопку отправки сообщения на форуме.
Если до этого вы уже выбрали файлы через «Добавить вложение», рисунок добавится к ним
(поле на форуме — multiple).

Окно создаётся один раз и не уничтожается при закрытии, поэтому при повторном нажатии **Paint**
в нём остаются и рисунок, и выбранные цвет/толщина/размер холста.

## Файлы

* `manifest.json` — описание расширения (Manifest V3, content script на `nosql.ru/forum/*`).
* `content.js` — весь код расширения.

## Замечания

* Интерфейс рисования в саму форму не встраивается: в форме живёт только кнопка Paint,
  окно лежит в `body` (вне `form`), поэтому ничего не ломает и не влияет на разметку форума.
* Пока окно открыто, прокрутка страницы отключена; при закрытии — возвращается.
* Расширение трогает только страницы `nosql.ru/forum/*`; если форма не найдена, оно ничего не делает.
* Размер холста меняется в пределах 100–2000 px (окно при необходимости прокручивается).
* Цвет по умолчанию — чёрный, толщина — 3 px.
* Круг-указатель рисуется на отдельном слое поверх холста, поэтому в итоговый jpeg он не попадает.
* Ничего на форум плагин сам не отправляет: он только заполняет поле выбора файла.
