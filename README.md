# Как поставить

## Шаг 1
```
mkdir ~/git
cd ~/git
git clone https://github.com/pavelkolodin/dedoforum-draw.git
```

## Шаг 2
Зайти сюда chrome://extensions/

## Шаг 3
Нажать эту пнопку

![Extension Button Load](./doc/img/install-extension-button-load.jpg)

Выбрать директорию из шага 1 (~/git/dedoforum-draw/)

## Шаг 4

Нажать F5 на форуме.

# Как пользоваться

## Написать пост

Пишем небольшой пост и жмём кнопку **Text**

![How To Use](./doc/img/how-to-use-1.jpg)

## Увидеть результат и запостить

Увидеть итоговую картинку, дорисовать туда сердечко кисточкой, нажать SEND.

![How To Use](./doc/img/how-to-use-2.jpg)

Файл приаттачится в форму и можно отправлять сообщение.
