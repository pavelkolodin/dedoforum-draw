# Как поставить

### Шаг 1
```
mkdir ~/git
cd ~/git
git clone https://github.com/pavelkolodin/dedoforum-draw.git
```

### Шаг 2
Зайти в Google Chrome на такую страницу `chrome://extensions/` и в правом верхнем углу включить галку "Developer Mode".

### Шаг 3
Нажать пнопку загрузки "незапакованных" extensions и выбрать каталог `~/git/dedoforum-draw/` из Шага 1 в появившемся окне.

![Extension Button Load](./doc/img/install-extension-button-load.jpg)

### Шаг 4

Нажать F5 на форуме. 

# Как пользоваться

### Сочинить текст

Сочиняем небольшой текст и нажать кнопку **Text**. Эта кнопка переведёт текст в красивую картинку и покажет в новом окне графического редактора.

![How To Use](./doc/img/how-to-use-1.jpg)

### Поревьюить макет и приаттачить его

Появится графический редактор с картинкой, которую можно дорисовать. Когда картинка устраивает,  нажать **ATTACH**. Картинка приаттачится в форму и можно отправлять сообщение.

![How To Use](./doc/img/how-to-use-2.jpg)
